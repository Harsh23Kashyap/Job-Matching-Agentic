## 1. Composite ML scoring

### What was built

- **`backend/core/component_scores.py`** — dimension scorers:
  - `experience_score` — candidate years vs job requirement
  - `compensation_score` — preferred salary vs job budget range
  - `location_score` — remote preference vs job remote policy
- **`backend/core/scoring.py`** — `compute_composite()` blending:
  - Semantic **40%**, Skills **30%**, Experience **15%**, Compensation **10%**, Location **5%**
- **`backend/core/matchmaking_scoring.py`** — wires `strategy: "composite"` into match pipeline
- **`backend/contracts/matching.py`** / **`snapshots.py`** — `MatchResult` exposes all component scores + `missing_skills`
- **Frontend default** — `DEFAULT_CANDIDATE_MATCH.strategy = "composite"` in `api/client.js`

### UX

- List cards show **final %** + band (Strong / Good / Moderate / Low via `matchTier()`)
- **`MatchDetailsDrawer.jsx`** shows five progress bars with weights in subtitle

### Tests

- `tests/unit/test_component_scores.py`
- `tests/unit/test_scoring.py` — composite weights, perfect alignment, gap penalties
- `tests/integration/test_feature_reverification.py` — API returns all five scores

## 11. Profile upsert & jobs page unlock

### Problem

Saving profile could fail with “Profile already exists”; Jobs page blocked search even when profile existed; empty `id: ""` in payload broke create path.

### Backend fixes

- **`PUT /candidates/me`** — true upsert (create + link if missing, update if linked)
- **`POST /candidates`** for logged-in candidates delegates to same upsert
- **`_sanitize_profile_payload`** — strips blank `id`
- **`auth/store.py`** — idempotent `link_candidate`; `clear_candidate_link` helper
- GET `/candidates/me` returns 404 when in-memory profile missing but **keeps ownership link** so PUT recreates same ID after restart

### Frontend fixes

- **`profileToPayload()`** — omits empty id on first save
- **`isCandidateProfileReady()`** — gates Jobs page (requires id + name)
- **`fetchMyProfileOrNull()`** — 404 → null without throwing
- **`Matches.jsx`** — refetch on profile update event + tab visibility
- **`saveCandidateProfile()`** — delegates to `upsertCandidateProfile()` (always PUT)
- Toasts: “Profile updated. You can refresh matches now.”

### Tests

- `tests/integration/test_candidate_profile_flow.py`
- `tests/unit/test_profile_fields.mjs`
