% --- Data availability ---
\section*{Data availability}
The frozen demo corpus (30 resumes, 15 job descriptions, 47 labeled pairs), the
synthetic corpus and generator, the evaluation scripts, the explanation generator,
the calibration layer, and the regression benchmark will be deposited in a public
repository (Harvard Dataverse) with a citable DOI upon acceptance; an anonymized copy
(author identifiers removed from the released code and test fixtures) is available to
reviewers during review. The release includes the one-command
reproduction script, the auto-generated tables, the per-experiment JSON artifacts,
and the figure source scripts.
