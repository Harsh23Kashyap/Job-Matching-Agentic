\subsection*{Data availability}
The project repository includes the demo corpus under \path{data/} and benchmark outputs under \path{backend/benchmark_outputs/} and \path{docs/research/evaluation/}.

\subsection*{Code availability}
Source code for the platform, benchmark drivers, and regression tests is available in the JobMatch repository at the submission tag.
Key entry points include the backend gateway and agents, the matching core, the React frontend, and benchmark regression tests.
The repository is hosted at \url{https://github.com/Harsh23Kashyap/Job-Matching-Agentic}.
