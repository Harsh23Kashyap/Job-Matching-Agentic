## Figure borders

- **Diagram PDFs (Figs 1–9):** neutral `#94a3b8` frame at compile time via `\JFigFramed` in `manuscript/jaamas-macros.tex`.
- **PNG previews + screenshots:** baked frame via `apply_figure_borders.sh` (or `crop_figures.py --borders-only`).

```bash
cd docs/submission/jaamas/figures
bash apply_figure_borders.sh
```

Figure 10 uses `\JFigShot` (pre-bordered PNGs) to avoid double frames in the PDF.

## LaTeX manuscript

Figures are included via `\JFigure{../figures/FigN.pdf}` in:

- `manuscript/sections/section-3-architecture.tex` — Figs 1–7
- `manuscript/sections/section-4-implementation.tex` — Fig 8 + Fig 10 (screenshots)
- `manuscript/sections/section-5-quality-metrics.tex` — Fig 9

Labels: `\figcap{N}{...}` → `\label{fig:N}`. Cite with `Figure~\ref{fig:N}`.

Legacy draw.io export (optional): `python3 scripts/generate_jaamas_figures.py` (Figs 1–5 draw.io only).
